# v015 收窄手写 PV 到 BS32 或 S8
起点：v014 局部 case 6/12 连续两轮收益，case 11 未稳定获益；v009 为 OJ 已接受版本。
假设：仅对 block_size=32 或 S=8 使用 v013 的 K16+linear V 手写 PV，其余采用 v009 T.gemm PV，能保留两个重复收益并减少不确定分流。
机制：仅修改 v014 的 use_manual_pv 条件，不改任何计算、布局、QK 或测试入口。
预测：官方 case 6/12 与 v014 生成相同手写代码；其余 12 个形状与 v009 相同，局部收益重复。
证伪：正确性失败、生成代码不符、重复计时不能确认 case 6/12 收益。
风险：参数边界覆盖、时间波动；在线 OJ 尚需用户提交验证。
