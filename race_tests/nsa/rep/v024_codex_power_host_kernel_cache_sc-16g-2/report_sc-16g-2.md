# v024 kernel 对象缓存 / sc-16g-2

## 1. 上版本遗留问题

v023 case2 为13.2405us，v28 为9.349us；配对设备时间均5.888us。

## 2. 问题原因分析

 run_kernel 调用 JIT factory 带来 host dispatch 开销。

## 3. 本版本解决方案

python - <<'PY' kernel 对象。每次仍启动完整计算，不缓存 tensor 内容或结果。

## 4. 具体落地策略

(B,L,H,HQ,D,S,BS,causal)作字典 key。两个设备 factory AST 不变。新导出全14份代码，case12 C++ 与 v023 字节相同。
